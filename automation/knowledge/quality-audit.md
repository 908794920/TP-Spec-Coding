# Knowledge L4 Semantic Audit — Conversational Model Contract

Use the deterministic plan generated by `ai-work knowledge audit`. Review only the plan scope unless `--full` was explicitly requested.

For every mandatory canonical:

1. Read the canonical claim and the evidence/source bound by the plan.
2. Challenge whether the evidence supports the wording and precision.
3. Distinguish current fact, historical observation, compatibility/retired mechanism and inference.
4. Verify responsibility/enforcement owner for statements such as “must”, “guarantees”, “current entry”, “only”.
5. Check whether the content duplicates another canonical and should be merged/updated instead.
6. Check numeric/API/config assertions against real evidence.
7. If source changed but canonical need not change, record why.

Unattended mode: do not ask the user questions. Any unresolved contradiction, missing evidence, destructive merge/split or project-assignment ambiguity is `FAIL/NEEDS_REVIEW` and the previous baseline must remain trusted.

Record PASS only after the actual plan has been reviewed:

```text
ai-work knowledge audit-record --result PASS --summary "..." --document <id-or-path> ...
```
