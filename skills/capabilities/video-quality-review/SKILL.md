# 视频成片审看

1. 先定位实际可播放的导出及其版本。正式 Task 使用实际审看的同 Task 导出事件；交接写明文件、版本、检查者和检查范围。制作人员检查自己的输出按自检记载，只有实际独立执行者做过检查才登记独立审看。
2. 按有效简报、约定规格及相关片型检查。记录文件与规格探测、播放范围、听音范围及各自的实际工具或执行方式。结合片型核对剧情连续性、广告主张／品牌／行动指引、知识依据／图示／字幕等真实适用项。文件可读、探测通过、能播放、听音通过及实际投放或学习效果是不同观察。工具缺失、只能抽看或未能听音时如实写明未检查范围和影响。
3. 用时间码、镜头、音轨或字幕定位问题，附观察到的结果、预期、影响和返修责任。重导出后核对同一问题及受影响范围，继续沿用仍适用的证据。需要品牌、专业内容或教学效果确认时，以对应来源或实际结果为据。
4. 用户接受单独留证，绑定用户实际审看的导出、用户真实决定和覆盖的验收项。正式登记使用该同 Task 导出事件 ID。若写入前当前版本已变更，先核对用户决定所指的版本，原决定不能转给新版。交付收敛或授权发布分别记录，技术或独立审看结果不替代用户接受。
