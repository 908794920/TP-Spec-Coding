# PowerPoint：主题复用与可编辑交付

适用于产品介绍、工作汇报、售前与 BP 的新建和增量编辑。内容角色决定事实、叙事、数据及来源；本参考只处理格式和对象保真，不增加商业承诺、财务数据或固定页数。

## 选择格式依据

用户明确要求及适用客户/合同/招采模板优先；增量默认保留既有有效格式；再选适用且已核实的参考，最后才用设计默认。模板仅作为内容来源时，不自动照搬品牌。冲突影响内容、兼容性或完整性时列出具体影响交用户决定。普通可逆的局部排版按现有上下文继续，不增加固定问卷或输入拒绝门槛。

## 锁定与应用本次基线

有模板/既有 deck：保留原件，记录 hash、用途、允许修改范围；读取真实 slide size、theme 字体/色板、master/layout 关系、占位符位置、页脚和本次涉及对象。按原 ID/对象复用或复制实际布局，不凭截图猜一个相似主题。模板字体缺失时报告具体字体及版式影响；一般可逆替代需说明并锁定，涉及客户要求或完整性重大取舍时交用户选择。不得静默全篇换字体。

无指定模板的新建使用 [最小主题片段](../examples/powerpoint-theme.mjs)。它只设置现有 Artifact Tool 的主题并返回实际对象可绑定的样式，不解析、导出、渲染或创建固定版式库；没有安装 Artifact Tool 的宿主沿用其已装工具表达同一选择，不为片段自动加依赖。

| 候选设计默认，非国标/行业硬门槛 | 原生绑定与复用 |
| --- | --- |
| 无尺寸要求时 1280×720，即 16:9 | 新建 `Presentation.create({slideSize: powerpointDefaults.slideSize})`；客户/既有尺寸直接保留，不用默认覆盖 |
| 标题黑体32pt，正文宋体20pt，必要注释宋体14pt | 新建后 `const styles = applyPowerPointTheme(presentation)`，对象 `text.style = styles.title/body/note`；图表标题、轴、图例、标签分别绑定；现有工具数值 `fontSize` 为 px，片段显式使用 `fontSize: "32pt"` 等单位字符串，并核对导出实际字号 |
| 黑、白、中性灰及单一强调 `#1F4E79` | 片段定义完整 theme colorScheme；同语义对象复用 `tx1/tx2/accent1`，不另挑一套色板 |
| 实际用到的 master/layout/placeholder | 用现有后端设置标题/正文占位符的对应样式，slide 引用其 layout；同类新增页复制实际原生布局，不规定数量 |

14pt 注释仅为近距离屏幕阅读的候选，关键结论/数据不可藏进小字。真实投影需要更大字体时放大、调版或合理拆页，先保留内容，再解决空间；固定页数与完整性冲突时说明取舍。标题和数据标签也要实际检查中文回行、层级、对齐、对比、单位、阅读顺序与必要替代文本，不用颜色独自表达关键信息。没有理由时不加封面、目录、卡片网格或装饰图。

片段首次使用前核实目标渲染环境的真实字体 family；本次 Windows 字体发现可用“黑体”“宋体”，不随 Base 分发字体，字体版本、嵌入和授权仍依实际环境。首次选定字体、主题与偏离记入已有证据或文件旁短说明，同批和后续增量沿用。不要在既有 deck 上调用默认主题片段。

## 新建与局部编辑

1. 新建从客户模板复用真实 slide、master/layout 与占位符；无模板时只定义本次用到的布局。文本、数据表、图表及约定可编辑的图使用原生对象，保留全部行列、数据、单位、来源和必要说明。图表内嵌工作簿/公式有要求时保持真实来源，不能拿字面快照替代既有公式。
2. 增量先渲染相关原页，定位对象 ID 与结构基线，在副本定点修改文字、单元格、数据或占位符。只改本次对象和必要受影响依赖，不整 deck 重建或经 Markdown 往返。未改对象（含备注、链接、图像裁切等）按影响核保留。
3. 仅当要求全局变化时改共享 master/layout/theme，并核查每张实际受影响 slide。新增同义对象继承相邻样式；少见的动画、OLE、嵌入或签名等先核字节/对象及后端支持，局部不支持不等于输入非法。
4. 后端不能保留对象时先说明精确缺口，尝试已有原生工具/局部保留；转换、丢失编辑性或丢对象的重大取舍交用户。不能静默扁平化、删页或用全页截图冒充可编辑 PPTX。

当前已验证的窄替代：现有 Artifact Tool 导入/导出含嵌入工作簿的样本时会丢失该工作簿，不能用于该样本的保真回写。对已经定位的一处文字，可用标准库 ZIP/XML 在副本中读取精确 slide part，确认唯一目标文本及允许范围，仅替换该文本，再写回 ZIP；比较其他每个 part 的解压字节、relationships 和对象数据均保持，再用可用工具渲染。不要全量 XML 重序列化、按模糊全文替换、重建图表数据或把这条窄方法当通用编辑引擎。其他对象编辑需另核实际工具能力。该宿主导入后的 placeholder 继承预览也有位置/字号缺口，不能只凭该预览判原件损坏；新建时可将已锁定的布局几何/样式明确绑定本地 placeholder，仍保留 master/layout 关系，再用另一实际渲染器对照。

## 检查与交付边界

结构：比较完整文本/表图数据、原生对象类型/数量、尺寸、主题字体/色板、master/layout 引用、备注/链接及本次特殊对象；核对改动目标正确、未授权页和对象保持。不同工具可能重排 ZIP、ID、缓存，hash 用于绑定文件身份，不能仅因字节不相同判格式漂移。

运行与视觉：用当前宿主要求的 finalizer/结构检查导出独立结果，按宿主要求真实渲染，新建逐页检查长中文、溢出、遮挡、表图标签和引用。局部编辑前后对照修改及实际受影响页；若改共享样式，覆盖其全部影响页。需要验证稳定性或存在已知漂移风险时，用副本重复打开/保存，观察相关内容、对象、样式和关系，不重复应用新建主题。

Artifact Tool 的 PNG 是该渲染器的实际预览；LibreOffice/WPS/PowerPoint 各自打开、编辑、保存与放映的观察另记。使用 LibreOffice 自动化时用独立 user profile，不停止用户已有进程。只在确实打开检查了 PowerPoint 后才声称 PowerPoint 已验证。

三类新建用途用代表性内容验证即可，不机械各造一套引擎。证据分别记录实际输入/输出 hash、工具版本与字体、命令/API及合成数据、结构结果、渲染页、未执行的目标应用项；开发自测不代替独立测试或用户接受。临时验证脚本与中间夹具依本仓 TESTING 清理，保留真实结果和获准样稿。工具/字体/渲染缺失时交付可靠的可审阅范围并说明恢复条件，不能以文件已导出声明视觉或兼容性 PASS。

## 大纲与排版边界
获准重组汇报内容，且用户要求金字塔原理或页间主线不清时，内容负责人按[汇报大纲](../../../roles/tp-product-manager/SKILL.md#汇报大纲)先组织结论和依据。纯排版任务保留原内容结构。
