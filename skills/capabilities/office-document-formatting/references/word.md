# Word 格式执行与保真

用于需求、设计、测试、手册、技术白皮书、商务及投标材料的 DOCX 新建和既有文件增量编辑。内容及专业结论归当前内容角色；本参考只负责格式依据、原生样式和实际检查。已有文件已满足要求时沿用，不为调用本能力重新排版。

## 先选择适用依据

用户明确要求及适用客户、合同、招采模板优先；局部编辑随后沿用有效既有结构与格式；没有这些依据才选择适用文种规范或下文普通参照基线。冲突涉及内容、完整性或兼容性时列明具体影响交用户决定，不默认覆盖。模板只用于本次获准目录，保留原件与 hash，不把客户模板、业务内容或字体打包进公共 Base。

需求规格可导航到 GB/T 9385、8567 和 ISO 29148，设计可导航到 GB/T 8567，测试可导航到 GB/T 9386，用户手册可导航到 ISO 26514。它们的本次读取深度如下，不能从目录补造章节、必填项或符合性结论。投标文件的实际招标文件、补遗和答疑优先；白皮书和商务方案按读者、已确认内容与委托模板组织，不杜撰通用国标目录。工程编号如 1、1.1、1.1.1 保留，不强改为公文序号。

## 无指定模板的普通参照基线

唯一实现是 [word-styles.py](../examples/word-styles.py) 中 `apply_reference_styles(document)`，以已装 `python-docx` 的 Document 对象调用。它只设置当前新建文档的节和原生段落样式，不生成内容、编号、目录、页眉页脚，不保存或渲染文件。它不是整体规范化既有文档的入口；已有模板不用此默认片段覆盖。

| 对象 | 确定参数及原生绑定 | 依据及界限 |
| --- | --- | --- |
| 页面 | A4 210×297 mm；上37、左28、右26、下35 mm | GB/T 9704 5.1、5.2.1 的上/左和156×225 mm版心；右/下是几何推算，并非原文直接规定的两个值 |
| 正文 | `Normal`，仿宋（FangSong）16pt，黑色，首行32pt（两字） | 参照5.2.2、5.2.4、7.3.3的三号仿宋；实际字体选择不等于某厂商字体文件获准分发 |
| 标题 | `Title`，黑体（SimHei）22pt，黑色居中，段后16pt | 普通文档明确采用已验环境黑体代替7.3.1的小标宋，属于参照偏离，不能宣称真公文标题符合 |
| 一级至三级标题 | `Heading 1/2/3`，分别黑体/楷体/仿宋16pt，段前12pt、后6pt，和下段同页 | 参照7.3.3的层次字体；字号、间距及原生样式绑定是普通文档设计选择，不改工程编号定义 |
| 普通段落节奏 | 1.5倍行距、正文段前后0、孤行控制；标题首行不缩进 | 是本基线实现选择；没有声称“国标固定28磅”。真公文一般22行×28字须按5.2.3及实际例外核网格和实排 |

中西文 `ascii/hAnsi/eastAsia/cs` 显式绑定实际家族，移除这些已设置样式上的字体 theme 引用和默认模板装饰边线。已验 Windows LibreOffice 对英文 FangSong/KaiTi 家族名出现错误替换；片段使用同一字体文件的中文家族名“仿宋/黑体/楷体”，并以实际 PDF 字体资源验证。其他引擎仍须核实际采用结果，不能只查注册表。片段保留更深标题、代码、公式、引文及其他专用样式；作者按本次内容显式使用相应原生样式，不对所有段落强套 Normal。字号间距不足时以真实内容局部调整并记明，不截掉内容。

本次样例环境为 Windows 已注册的 FangSong、SimHei、KaiTi、SimSun；小标宋未发现。其他环境先核实际字体及授权，复用同批已锁定的家族；缺失时报告影响和实际替代，不静默变换。真公文若要求小标宋，其字体及全面适用条款仍为前置；上述黑体偏离不能代替符合性核查。不自动安装、嵌入或分发字体文件。

普通参照文档不凭空添加红头、密级、发文字号、机关身份、印章或版记。页码按用途采用简洁连续页码是项目选择；真公文应另核7.5的字体、奇偶页、位置与例外。电子文档的属性和渲染不能证明纸张、印制装订符合。

## 新建和局部编辑分别执行

**新建**：先保留来源、实际字体和格式选择；有指定 DOCX 模板时复制原件、复用其 styles、编号定义、节和组件。当前宿主若提供 Documents，参考模板控制新文档时按其 `template-distill → template-create` 执行；无模板才用上述基线。内容角色决定实际目录和对象，不能为模板虚构章节或结论。

**既有文档局部编辑**：先记录原件 hash、目标对象及相关结构/渲染基线，再在副本定点修改文本节点或原生对象。增补同语义内容克隆相邻同类段落/表格并保留真实 style、numId/ilvl、关系和节设置；不重建全篇，不使用 Markdown 往返。此流程不套新建模板的整份 slot map 契约，也不默认清除全部直接格式。现有低层 OOXML helper 先查本次操作支持，不当作通用编辑引擎。

按实际触及对象核对：标题层级和列表编号；表格列宽、单元格边距及跨页重复表头；图题与图片锚点/替代文本；节、方向、页眉页脚与页码；目录、书签、交叉引用、链接；批注、修订、公式和内容控件。`Document.paragraphs` 不覆盖文本框、页眉页脚等所有内容，不能单靠其数量证明完整。触及域时保留域代码并核实际更新；未能在目标应用刷新，明确缓存/更新状态，不能将设置 updateFields 当作已刷新。

未知或少见结构先查看真实字节、包结构与工具能力，不据此拒绝整份输入。旧 DOC、宏、签名、嵌入对象或需格式转换时说明受影响对象、保留办法与具体损失；涉及重大完整性/编辑性取舍由用户决定，不改扩展名伪装转换，不静默丢弃。

## 工具和交付检查

Base 不固定机器路径、宿主版本或强制安装。发现当前宿主已有 DOCX 工具后，复用其 author/edit/render 方法。Codex 下遵守 Documents 的 dependency loader、操作标记和渲染要求；当前 Windows renderer 使用本机既有 native LibreOffice，Python及Poppler按 loader 返回值选择，记录实际版本，不混用旧 PATH 程序冒充同一环境。其他宿主可用已有 Word/WPS 原生工具或已装库；缺少渲染时可保留可审阅草稿并声明恢复条件，不报视觉通过。

交付前完成两个互补检查，并单独说明人工接受状态：

1. **结构及运行**：核对目标内容与未授权范围，检查实际样式/字体绑定、节、编号、表格、图及本次涉及的关系和域；保存可编辑源文件、来源/输出 hash 与工具环境。局部编辑比较相关包成员及关系；重复一次不改内容的编辑/保存，比较内容和格式语义，不要求 ZIP 字节相同。实际打开/编辑/域更新在哪个程序运行就写哪个，不把 LibreOffice 结果称为 Word/WPS 通过。
2. **真实渲染**：按宿主要求用现有 renderer 生成 PNG。新建逐页查看；局部编辑对照原件与结果，核对目标页及实际受影响页（含受影响的后续分页）。按实际范围核字体、缺字、长内容分页、表头续页、图题、页码、孤行、裁切和重叠。可用现有 render-and-diff 辅助，像素差异不代替结构检查。修改后重新渲染并复看受影响范围；只有属性通过、文件可保存或能下载均不足以交付为视觉已验。

报告分别列出结构检查、实际程序运行、真实视觉、未执行项和人工接受；不声称跨任意 Office/WPS/字体逐像素一致。通用基线片段不含作者引擎或测试框架；当前功能临时测试和夹具按仓库验证策略清理，证据留任务目录。
