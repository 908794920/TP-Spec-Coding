# Office 文档格式化

## 触发与责任

用户要求创建、调整、续写或交付 Office 文件，或要求按客户模板/适用规范稳定格式时读取。需求、产品、设计、计划、测试和交付阶段均可用，pre-task 也可用；普通 Markdown、Runtime 登记及无需改变的文件不触发，不因此创建 Task、切换阶段或建立新角色链。

内容事实、业务规则、计算口径与专业结论归当前内容角色；格式处理不得暗改内容、承诺、代码、公式或引文。集成交付工程师维护共用方法与最终格式核对，不代签其他专业结论或用户验收。已有格式已满足目标时保留或复用，不为调用能力制造修改。

## 格式依据与按需导航

沿用已有上下文识别用途、读者、目标格式及新建/增量，缺少会改变结果的信息才澄清。按以下顺序选择：

1. 用户明确要求和适用的客户、合同、招采或机构模板。
2. 增量编辑中仍适用的原文档格式与结构；新增同语义内容复用相邻同类原生样式。
3. 已核实适用范围与读取深度的文种规范。
4. 相应介质的保守默认。Word 以 GB/T 9704 的适当排版兜底；Excel/PPT 不套公文。

同层规则或模板有重大冲突时说明具体影响，交用户决定；一般可逆局部选择依上下文处理。标准条款、设计默认、推算和未核实内容分开，不能用目录/摘要宣称全文符合。

## 固定基线与实际操作

1. **保留原件并确定范围。** 记录实际输入/模板版本或 hash、本次对象和允许变化。客户原件与数据留客户项目/授权目录，不复制进公共 Base。普通文件工作不强制 Task 或 JSON sidecar；已有任务直接复用证据位置。
2. **固定格式权威。** 有客户模板或有效既有文件时复用其原生 styles/numbering、cell formats、theme/master/layout 和实际字体，不套默认。无模板新建才使用对应参考及小片段；在同一文档/同系列后续编辑复用已锁定基线，不重新选择字体、编号、配色。片段只应用样式，不负责内容生成、解析或渲染。
3. **按动作编辑。** 新建可建立所需原生样式/主题；从模板新建复用模板结构。局部编辑独立捕获相关结构与渲染基线，修改授权对象及必要依赖，不重建全篇。Word 的模板 distill/create 仅用于模板控制新建，不套到原件局部编辑；低层 OOXML helper 只用已确认支持的操作。
4. **使用真实可用工具。** 按介质参考调用当前宿主工具和已装依赖，在副本/新输出完成。中间预览与临时脚本放任务受控临时目录；客户结果与必要证据按用户要求保存。除已有明确替换授权外不覆盖原件。
5. **核对结果再交付。** 按下节分别检查内容结构、实际运行/重算、真实渲染及接受状态；结果需能回到本次输入/输出、操作范围和工具环境。失败修当前范围，复用未变化且仍有效的检查。

中英文空格、标点、大小写等清洗不是默认内容修改授权；代码、路径、公式、标识符和引文尤其保持必要字面值。不要添加固定封面/目录/修订表、全数值汇总、固定页数/版式或其他无依据规则。

## 工具与兼容边界

优先复用当前宿主的文档/表格/演示能力、平台功能及已装依赖，不另建解析器、渲染器、统一内容 JSON 或调度服务。Base 的 `document convert` 是本地内容到 Markdown 的摄取工具，不能用作保真增量保存的中间格式，也不为一次客户文件编辑启动 Knowledge batch。

在 Codex 环境按实际宿主 Skill 与 workspace dependency loader 选 Node/Python/库；不要复制插件 cache、固化机器路径或给 Base requirements 添加宿主依赖。其他宿主可用其现有原生工具/已装库，先核本次对象支持。默认基线片段各只有一个已声明后端，不自动安装或切换多套实现。

宿主默认 Spaces、云端连接器或模板库不构成自动外发权限；按用户的本地/云端目的地执行。没有必要不上传、安装依赖/字体或使用付费服务。实际字体需可用且获准使用，正常文档内嵌核许可与应用支持，不擅自分发字体包。字体缺失/替代说明实际范围与版式影响，重大取舍交用户。

旧扩展名、未知排版、宏、签名、OLE/外链或局部不支持不等于整份输入非法。先查真实字节/结构及当前工具能力，保留可处理与未改部分；不能静默丢对象、扁平化、只改扩展名伪装转换或伪报完整保真。需要改变内容、编辑性、文件格式或签名等重大结果时，说明具体损失、替代和验证缺口，交用户决定。

## 验证与完成

- **内容与原生结构：** 核对目标变化与未授权范围。Word 检查被触及的样式/编号/节/页眉页脚/域与图文关系；Excel 核值、类型、公式/引用、对象/验证；PPT 核原生对象编辑性、主题/母版/布局。不能用截图/PDF代替可编辑成品。
- **运行与计算：** 涉及公式、目录/域更新、输入驱动图表或其他原生行为时，在实际支持的引擎验证。写入公式、缓存值、成功 import/export 不等于已计算、已更新或在目标应用通过。Excel 重处理比较值/类型/公式/引用/对象/格式及适用重算和保存差异；不要求每次无编辑重算、缓存完全相同或 ZIP hash 相同。
- **真实渲染：** 新建审所有页/Sheet/slide；局部编辑审修改及实际受影响范围，Word 包含必要后续分页、PPT 包含共享母版受影响页。检查缺字、截断、溢出/遮挡、字体/层级、表格图表及适用打印视图。结构检查不能代替视觉。Artifact PNG、LibreOffice/WPS和真实 Microsoft Office 各自记录，不能互相冒称。
- **稳定性：** 本次要验证模板、样式或重复处理的稳定性，或存在已知漂移风险时，用副本验证同语义增补或重复处理，比较相关原生结构与内容副作用；不比较无关打包元数据来判漂移。缺工具只停止受影响检查，报告恢复条件，不把未测改成 PASS。

交付用户请求的可编辑文件；内部脚本/预览仅在要求或需要解释结果时提供。说明实际采用的模板/规范/默认、偏离项、结构/运行/渲染各自结果、未验证的目标应用及剩余限制；人工接受只能来自用户，不由格式执行者代签。已有正式 Task 继续按其有效产品 AC 与原门禁登记，不把规划接受、开发自检、文件生成或导航可读当作产品通过。
