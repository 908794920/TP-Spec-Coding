# 视频镜头制作

1. 读取本次镜头 ID、画面目的、连续性约束、参考及交付规格。先判断现有素材、实拍、确定性合成或生成中何者足够完成当前镜头。多镜头工作沿同一选用清单，避免并发覆盖同一路径。
2. 生成前核对工具支持所需输入和输出，确认本次费用、上传内容及素材用途确有授权。用最小必要样段探查高不确定性。调用失败先定位工具、输入、约束、授权或输出问题，再选择局部重试、改用已获准素材或人工修补。遇到实际权限、费用或能力阻塞，保留可继续的提示词、参考、镜头要求或导入包，并标为待生成／待导入。
3. 对实际输出按镜头目的、相邻镜与交付规格选片。交付候选和采用状态、真实路径／版本、可核对的制作来源、受影响的下游与未检查范围。记录真实生成任务 ID 或实际配置时，仅写工具确实给出的值。生成回执与实际可播放文件分开。

跨工具、多镜头复用或需要可复现补镜时，加载资产与配置交接说明。 [生成资产交接](references/generation-handoff.md)
