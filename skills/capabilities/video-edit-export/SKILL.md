# 视频剪辑与导出

1. 按稳定镜头或素材标识接收当前版本及需要复用的部分；已有正式 Work 收据时引用实际回执。涉及共享主时间线时明确写入者。镜头合成或修补可独立交回，由主时间线负责人核对并合入。先确认需要的字幕、文本稿、音轨与渠道版本。
2. 在当前可用剪辑工具内完成需要的剪辑、合成、字幕、混音和导出。按已确认规格处理画幅、时长及可读性；分渠道导出只覆盖已约定的变体。需要返修时定位轨道或时间段，保留不受影响的画面、声音、字幕和当前可用的上一版。无法实际剪辑或导出时交可续编说明和导入素材，标明缺口。
3. 按约定交付实际审看版或成片及必要附属文件，记录路径、版本、实际工具输出与未检查范围。续编属于本次交付时提供主工程或可续编说明；用路径和版本引用关键素材，已有正式 Work 收据时附实际回执。成片在获准位置保留，正式 Task 按当前视频 Runtime 登记实际导出及小型清单。导出后按实际规格检查，自查以自检身份交接。 [成片审看](../video-quality-review/SKILL.md)
