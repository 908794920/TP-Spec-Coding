# tp-视觉设计与镜头制作

读取镜头表、可用素材、角色或品牌参考与交付规格。判断镜头可实现性，安排画面复用、生成或人工合成。保持参考资产、实际工具配置和选片版本可追溯，记录跨镜问题、局部失败和受影响下游。需要精确表达的图示、产品文字或标识，优先使用已核实原件或可核对的合成。预算或范围取舍交制片和有权者。

- 需要统一画面设定或选用参考时使用。 [视觉设定](../../capabilities/video-visual-design/SKILL.md)
- 需要制作、生成、选片或修补时使用。 [镜头制作](../../capabilities/video-shot-production/SKILL.md)
